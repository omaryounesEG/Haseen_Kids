# Haseen Kids | حَصِين للأطفال — Release 1.2.0 🛡️

**Smart family protection + an isolated, ad-free YouTube player for Windows (7 SP1 → 11).**
Arabic-first UI, works fully offline after installation.

---

## What's new in 1.2.0

### 🎨 A brand-new child-friendly interface
- Bright, playful palette (violet / teal / pink) with soft 20px rounded corners.
- Bundled **IBM Plex Sans Arabic** font at a larger size (15px body, 26px headings).
- A plain-Arabic explanation popup (tooltip) on **every** button before it is used.
- Child dashboard: a 🦉 greeting card plus three large action tiles.

### 🌐 One whitelist entry covers every browser
- An allowed site works on **Chrome / Edge / Brave / Firefox** and on **all** of its
  sub-domains (`app.classera.com`, `cdn.static.classera.com`) and resources (fonts, scripts).
- **A YouTube video embedded in a school lesson (Classera) plays inline** through `/embed/`
  with no block screen, and `/watch` links open automatically in the clean ad-free player —
  **no parent approval, no waiting**.

### 📨 Approvals finally work end-to-end
- The child requests access from the block page → the parent approves from the new
  **“Child Requests”** tab → the site **opens on the child's machine within seconds**
  (permanent, 30-minute, or reject).
  *(Previous defect: approvals were recorded but never unlocked anything — fixed and verified live.)*

### 🆘 Forgotten password / final removal — fully offline
`Haseen_Remove.bat` offers three independent paths:

| Path | Requirement |
|---|---|
| 🔑 Recovery key `XXXX-XXXX-XXXX-XXXX` | Generated by the setup wizard, saved to `Documents\Haseen_Recovery_Key.txt` |
| 🪟 Windows Administrator account | No key, no email — the admin account is enough |
| 🔓 Parent password | For a full removal including program files |

### ⚙️ Simpler installation
- A single `Setup.bat`: find Python → create the environment → install packages →
  check the machine and browsers → parent password → **recovery key** →
  desktop shortcut + auto-start.
- **Updating never wipes** the password, the lists or the logs (the database is excluded
  from Git and from the update copy).

### 🔒 Security fixes
- Removed a hard-coded `H:\` database path (now relative) — it would have broken
  installation on any other drive.
- Tests now run against a throw-away database, so they no longer pollute the parent's lists.
- Exception requests sent as JSON were stored with an empty domain — fixed.

## Install with one line

**CMD**
```cmd
curl -sSL https://raw.githubusercontent.com/omaryounesEG/Haseen_Kids/main/install_from_github.bat -o install_from_github.bat && install_from_github.bat
```

**PowerShell**
```powershell
powershell -NoProfile -ExecutionPolicy Bypass -Command "[Net.ServicePointManager]::SecurityProtocol = [Net.SecurityProtocolType]::Tls12; (New-Object System.Net.WebClient).DownloadFile('https://raw.githubusercontent.com/omaryounesEG/Haseen_Kids/main/install_from_github.bat', 'install_from_github.bat'); .\install_from_github.bat"
```

Or download the attached ZIP, extract it and double-click **`Setup.bat`**.
