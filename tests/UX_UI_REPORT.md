## 1) الهوية البصرية الجديدة (ألوان أطفال)

| العنصر | القيمة | لماذا |
|---|---|---|
| الخلفية | تدرّج بنفسجي/سماوي فاتح `#F4F1FF → #E9F7FF` | مريح للعين، لا يُجهد الطفل |
| البطاقات | أبيض نقي + حدود `#E6E0FF` + تدوير **20px** | إحساس لعبة، حواف دائرية بسيطة |
| اللون الأساسي | بنفسجي `#7C5CFF` | حيوي ومحبب للأطفال |
| لمسات | وردي `#FF6B9D`، تركوازي `#22C1A8`، أصفر `#FFD166`، برتقالي `#FF9F1C` | تفريق الأزرار بصرياً بلا نصوص طويلة |
| النص | `#2B2350` على فاتح (تباين ≈ 12:1) | يتجاوز WCAG AA بمراحل |
| الخط | **IBM Plex Sans Arabic** (مضمّن محلياً) + Segoe UI Emoji | عربي واضح بعرض مريح |

**الأحجام:** أساسي 15px، عناوين البطاقات 16px، عنوان الشاشة 26px، الأزرار 15px Bold — أكبر من الإصدار السابق (13–14px) بناءً على طلب «خط واضح حجماً».

## 2) الشاشات بعد التعديل

### لوحة الطفل
- **بطاقة ترحيب** مع رمز البومة 🦉 ورسالة شخصية.
- **3 بطاقات أفعال كبيرة** (فيديو نظيف / رصيدي اليوم / اطلب موقعاً) — بدل الاعتماد على التبويبات فقط.
- مؤشرات الوقت أُعيد توجيهها لتُملأ **من اليمين لليسار** (كانت تُملأ يساراً داخل واجهة RTL).
- شرائح التبويبات أصبحت "كبسولات" مستديرة، المحدد بنفسجي بخط أبيض.

### لوحة ولي الأمر
- شرح أعلى تبويب القوائم: **«قاعدة واحدة تكفي»** — يوضح أن الموقع يعمل في كل المتصفحات وكل الصفحات الفرعية.
- الجدول: رأس بنفسجي، صفوف مخططة، عمود النطاق يتمدد تلقائياً.
- تبويب التحديثات: بطاقة إصدار تعرض **الحالي مقابل المتاح على GitHub**.
- قسم **الاسترجاع والحذف النهائي** (مفتاح استرجاع + إزالة نهائية) داخل تبويب الصيانة.

### معالج التثبيت
- إصلاح كامل للتباين (كان نصاً أبيض على خلفية بيضاء).
- صفحة إعداد: خيار **«الإبقاء على كلمة المرور الحالية»** مفعّل تلقائياً عند الترقية.
- **مفتاح الاسترجاع** معروض بحدود متقطعة + أزرار نسخ/حفظ + توليد تلقائي.

### صفحة الحجب (في المتصفح)
- تصميم جديد بنفس الهوية: تدرّج بنفسجي، بطاقة بيضاء 28px، رمز متحرك 🦉.
- 3 مسارات للطفل: **طلب إذن** → حال انتظار بمؤشر نابض → فتح تلقائي عند الموافقة، أو **إدخال رمز** من ولي الأمر، أو **رجوع** للرئيسية.
- عرض الرسالة بالعربية مع سبب الحجب ونطاق الموقع.

## 3) الشرح التوضيحي (Comment popups)

كل عنصر مهم في الواجهة له تلميح عربي مبسّط يظهر عند الوقوف عليه، ويُبنى عبر `ui/theme.tip()`:

| العنصر | نص الشرح (مختصر) |
|---|---|
| زر لوحة ولي الأمر | «تفتح لوحة التحكم الكاملة… محمية بكلمة مرور حتى لا يدخلها الطفل» |
| شريط الترفيه | «عندما يكتمل الشريط تتوقف الألعاب حتى الغد» |
| شريط التصفح العام | «منصات المدرسة لا تُحسب من هذا الوقت» |
| حقل رابط يوتيوب | «يُفتح في المشغل النظيف: بدون إعلانات ولا مقترحات» |
| حقل النطاق | «اكتب اسم الموقع فقط… يفتح كل صفحاته وكل متصفح» |
| التصنيف / الإجراء | شرح EDU/SCHOOL/GAMING و ALLOW/BLOCK |
| مفتاح الاسترجاع | كيف ومتى تستخدمه، ولماذا يجب حفظه |

أسلوب التلميح: خلفية `#2B2350`، إطار بنفسجي، تدوير 12px، حجم 14px — «نافذة تعليق» واضحة لا شريط أصفر صغير.

## 6) توصيات للمرحلة القادمة

1. **وضع ليلي** للأطفال (تبديل تلقائي بعد وقت النوم) — الألوان جاهزة في `ui/theme.py`.
2. **أفاتار/شارات إنجاز** لتحفيز الطفل بدل الاعتماد على الألوان فقط.
3. **صوت تنبيه** قبل انتهاء الحصة بدقيقتين.
4. **ملف صور مضمّن** لشخصية حصين بدل الإيموجي (يظهر بنفس الشكل على Win 7).
5. إتاحة **تكبير الخط** من الإعدادات (المتغير `scale` موجود في `build_stylesheet(scale=…)`).
