## 1) أخطاء حرجة (Critical) — أُصلحت

### BUG-01 — مسار قاعدة البيانات مكتوب بشكل صلب `H:\` (حرج)
- **الأثر:** على أي جهاز لا يحتوي قرص `H:` كان البرنامج سينشئ قاعدة بيانات جديدة في مسار غير موجود أو يفشل الإقلاع. هذا يُبطل وعد "يعمل من أي قرص/جهاز".
- **الملف:** `database/db_manager.py`
- **السبب:** `DB_PATH = "H:\\Haseen_Kids\\database\\haseen.db"`
- **الإصلاح:** المسار أصبح نسبياً محسوباً من موقع الملف `os.path.dirname(__file__)`، مع دعم متغير `HASEEN_DB` للاختبارات.
- **التحقق:** اختبار تشغيل النسخة من مسار مؤقت + تشغيل كامل الاختبارات على قاعدة مؤقتة.

### BUG-02 — تحديث البرنامج يمسح كلمة المرور والقوائم (حرج) — أُصلح سابقاً وتأكد الآن
- **الأثر:** سحب التحديث من GitHub كان يستبدل `database/haseen.db` فيرجع كل شيء للافتراضي.
- **الإصلاح المؤكد:** القاعدة مستثناة من Git (`.gitignore`) ومستثناة من نسخ التحديث المباشر، وسكربت GitHub يستثني `*.db`.

### BUG-03 — القائمة البيضاء لا تعمل على كل مستويات النطاقات (حرج وظيفي)
- **الأثر:** إضافة `classera.com` لم تكن تفتح `app.classera.com` (ولا `cdn.static.classera.com`)، فتبدو المنصة "محجوبة" على بعض المتصفحات.
- **السبب:** البحث كان يقص مستوى واحداً فقط من النطاق.
- **الإصلاح:** `get_domain_decision()` يصعد كل المستويات (حتى 8) مع دعم لاحقات مثل `gov.eg` و`com.sa`.
- **اختبار:** `test_subdomain_of_whitelisted_site_is_allowed`, `test_email_root_walks_up_through_all_levels`.

## 2) أخطاء سلوكية (Behaviour) — أُصلحت

### BUG-04 — فيديو يوتيوب مدمج داخل درس (Classera) كان يُحجب
- **الأثر:** الطالب يفتح درساً فيظهر خطأ بدل الفيديو، أو يُطلب منه انتظار موافقة الأب.
- **الإصلاح:** سياسة يوتيوب ذكية ثلاثية:
  - `/embed/` و`youtube-nocookie.com` → **ALLOW مباشرة** (يعمل داخل الصفحة).
  - `/watch` أو `shorts` → **REDIRECT_YOUTUBE** يفتح المشغل النظيف تلقائياً.
  - أي حالة أخرى داخل يوتيوب → **ALLOW** (لا حجب ولا انتظار مطلقاً).
- **اختبار:** 3 اختبارات في `TestYoutubeInsideLessons`.

### BUG-05 — حجب HTTPS يُظهر خطأ متصفح بدل صفحة الحجب العربية
- **الأثر:** عند حجب موقع HTTPS يرى الطفل `ERR_TUNNEL_CONNECTION_FAILED` — لا يقرأ السبب ولا يطلب استثناء.
- **الإصلاح:** البروكسي يرسل ترويسات `X-Haseen-Blocked` + مسار `/blocked?domain=`، والإضافة (Chrome/Edge/Brave) تلتقط الخطأ وتفتح صفحة الحجب العربية. صفحة الحجب أُعيد تصميمها كاملة (ألوان أطفال، زر طلب إذن، إدخال رمز، انتظار تلقائي).

### BUG-06 — موارد المواقع المسموحة (خطوط/سكربتات/CDN) كانت تُحجب
- **الأثر:** الموقع مسموح لكن يظهر بلا تنسيق أو لا يعمل.
- **الإصلاح:** قائمة `INFRA_ALLOWLIST` (gstatic, googleapis, jsdelivr, cloudflare, googlevideo, recaptcha…).
- **اختبار:** `test_infrastructure_cdn_always_allowed`.

### BUG-07 — تسرّب اختبارات إلى قاعدة بيانات المستخدم
- **الأثر:** تشغيل الاختبارات كان يزرع نطاقات وهمية (`THREAD_TEST`, `TEST_SQLI`, `'; drop table domains; --`) في قوائم ولي الأمر الحقيقية.
- **الإصلاح:** الاختبارات تستخدم قاعدة مؤقتة (`HASEEN_DB`)، وتنظيف 301 سجلاً ملوثاً من القاعدة الحقيقية.
- **التحقق:** بعد تشغيل المجموعة كاملة: عدد السجلات غير المُبذَّرة = **0**.

### BUG-08 — تحديث `check_for_updates` كان لا يُظهر رقم الإصدار الحالي
- **الأثر:** الرسالة "تم التحديث" فقط دون مقارنة.
- **الإصلاح:** بطاقة إصدار في اللوحة: `الإصدار الحالي v1.2.0` + `أحدث إصدار على GitHub v…` + رسالة «أنت على أحدث إصدار».

### BUG-09 — تعارض Watchdog مع المنفذ 8089 عند تشغيل الواجهة منفردة
- **الإصلاح:** فحص المنفذ قبل الإقلاع (`_ensure_embedded_services`) وإعادة استخدام الخدمة القائمة.

## 6) إضافات ما بعد المراجعة الحيّة (Live verification)

تشغيل فعلي للبروكسي كشف خللاً لم تكشفه الاختبارات الوحدية:

### BUG-13 — «موافقة ولي الأمر» لم تكن تفتح الموقع فعلياً (حرج)
- **كيف اكتُشف:** تشغيل حقيقي: طلب من صفحة الحجب ← موافقة ← `GET /check_status` ظل `allowed: false`.
- **السبب:** `check_status` كان يسأل محرك الفلترة فقط، وجدول `exceptions` لم يُقرأ مطلقاً. كما أن الموافقة المؤقتة (30 دقيقة) لم تكن تُسجّل انتهاء صلاحية، ولم يكن لها أي أثر على التصفح.
- **الإصلاح:**
  - `DBManager.has_active_exception(domain)` — تبحث في `exceptions` مع فحص `expires_at` والبحث صعوداً في نطاقات الأب.
  - `DBManager.grant_exception(domain, minutes=None)` — موافقة دائمة (تُضاف للقائمة البيضاء) أو مؤقتة بـ30 دقيقة، مع `reject_exception` و`list_exception_requests`.
  - `SmartFilterEngine.evaluate_url` يفحص الموافقة **قبل** كل شيء (حتى قبل القائمة السوداء والحصة).
  - `verify_and_apply_code` يضبط `expires_at` للرمز المؤقت.
- **التحقق الحيّ:** `allowed:false` قبل الموافقة ← بعد الموافقة `allowed:true` فوراً، والنطاق الفرعي `cdn.…` يُفتح أيضاً.
- **اختبارات جديدة:** 5 اختبارات في `TestParentApprovalLoop`.

### BUG-14 — طلب الاستثناء كان يُسجَّل بنطاق فارغ
- **السبب:** المعالج يقرأ `application/x-www-form-urlencoded` فقط؛ أي عميل يرسل JSON (مثل إضافة المتصفح) كان يُسجّل صفاً بلا نطاق.
- **الإصلاح:** قبول JSON + استخراج النطاق من الرابط إن غاب + رفض الطلب الفارغ برسالة واضحة.

### BUG-15 — أزرار «موافقة/رفض» بلون واحد
- **الإصلاح:** `#btnSuccess` أخضر متدرج و`#btnDanger` أحمر متدرج في `ui/theme.py` (قرار يُقرأ قبل الكلمة).

### مُلاحظة تشغيلية
`kill_haseen_processes()` تطابق أي عملية مسارها يحتوي `haseen` — وهذا **يقتل أيضاً** الاختبارات الجارية من داخل المجلد (حدث فعلياً: exit 15). سلوك مقصود عند الإزالة النهائية، لكنه يعني: لا تُشغّل الاختبارات أثناء الإزالة.

## 7) مراجعة v1.3.0 (بعد تجربة المستخدم على جهازه)

### BUG-16 — الفيديو يعمل بدون صوت إطلاقاً (حرج)
- **البلاغ:** تشغيل فيديو من مسار حَصِين يفتح المشغل بدون إعلانات لكن **بلا صوت**.
- **السبب الجذري:** يوتيوب أوقف تقديم الملفات المدمجة (progressive) لمعظم المقاطع.
  `info['url']` غير موجود، فالكود كان يقع على قائمة HLS وهي **صورة فقط** (`acodec='none'`)،
  فيُمرَّر للاعب مسار بلا أي مسار صوتي.
- **الإصلاح:** `_pick()` يفصل اختيار الصورة عن الصوت ويعطي الأولوية للمسارات المباشرة
  (mp4 للصورة، m4a للصوت) ويرفض ملفات m3u8 عند الحاجة للدمج؛ و`play_video` يمرّر
  `--audio-file` لـ MPV أو `:input-slave` لـ VLC؛ والمسار الاحتياطي لمشغل ويندوز لا يُستخدم
  إلا إذا كان الملف مدمجاً فعلاً، وإلا تظهر رسالة صريحة.
- **الدليل المقاس:** تشغيل VLC للمسارين ← WAV بطول 9.96ث وRMS=1021 (صوت حقيقي)؛
  تشغيل مسار الصورة وحده ← **0 بايت** (صامت).

### ميزة — إيقاف مؤقت من أيقونة الترس (v1.3.0)
- 15/30/60/240 دقيقة بكلمة مرور ولي الأمر، مع انتهاء تلقائي وزر استئناف.
- التخزين في `settings.paused_until`، ويقرأه `SmartFilterEngine.evaluate_url` قبل أي قاعدة
  (حتى القائمة السوداء)، ويظهر في `/status` كـ `paused` و`pause_seconds_left`.
- مُتحقَّق حياً: موقع محجوب `allowed:false` ← إيقاف 15د ← `allowed:true` ← استئناف ← `false`.

### تحقّق — تغطية النطاقات الفرعية (Classera)
13 اختباراً تؤكد أن `classera.com` وحدها تفتح كل النطاقات الفرعية (حتى `a.b.c.d.classera.com`)
وكل المسارات ومع منفذ صريح، ولا تفتح `notclassera.com` ولا `classera.com.evil.net`.
