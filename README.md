# حَصِين للأطفال | Haseen Kids 🛡️

**برنامج الرقابة الأبوية والحماية الأسرية الذكية على ويندوز**
بنية هجينة خفيفة (Lightweight Hybrid Architecture) تعتمد على خدمة خلفية معزولة وبروكسي محلي ذكي، ومحرك يوتيوب معزول بدون إعلانات نهائياً وبدون أي تحميل مسبق أو استهلاك للباندويث.

---

## 🌟 أبرز مميزات النظام

1. **محرك يوتيوب المعزول (Clean YouTube Engine)**:
   - تشغيل فوري بدون إعلانات (Zero Ads) عبر استخراج رابط البث الخام (`.m3u8` / Direct Stream) من سيرفرات جوجل مباشرة عبر `yt-dlp`.
   - دمج تلقائي مع `SponsorBlock API` لتخطي إعلانات الرعاة ومقاطع الترويج داخل صلب الفيديو.
   - يدعم التشغيل عبر VLC و MPV والمشغل الداخلي.

2. **الفلترة الذكية ثلاثية المراحل (Zero-Token Waste Strategy)**:
   - **المرحلة 1 (0 توكن)**: فحص لحظي في 1ms عبر القوائم المحلية البيضاء والسوداء في SQLite.
   - **المرحلة 2 (0 توكن)**: كاش القرارات السابقة لعدم تكرار الفحص.
   - **المرحلة 3 (Micro-Prompting ~30 توكن فقط)**: استعلام مضغوط جداً يسحب فقط عنوان ووصف الصفحة ويصنفها عبر Gemini 1.5 Flash أو DeepSeek، ويحفظ القرار للأبد.

3. **إدارة الوقت والتفريق بين المدرسة والترفيه**:
   - مراقب نوافذ نشطة عبر Win32 API.
   - **منصات المدرسة والتعليم (مدرستي، بنك المعرفة، خان أكاديمي)**: مفتوحة دائماً وبلا حدود حتى لو انتهى وقت اليوم.
   - **عداد الترفيه والألعاب**: مؤقت تنازلي يومي ينتهي بالحجب التلقائي.
   - **ساعات النوم (Bedtime)**: إغلاق التصفح تلقائياً عند وقت النوم المحدد.

4. **الموافقات الفورية والتقارير الأسبوعية (Approval & Reporting)**:
   - توليد رموز موافقة ديناميكية (HMAC-SHA256) بدون الحاجة لسيرفر خارجي (رمز فتح دائم + رمز تمديد 30 دقيقة).
   - إرسال بريد فوري للأب عند طلب الطفل لأي استثناء عبر SMTP.
   - تقرير أسبوعي يلخص النشاط بالذكاء الاصطناعي ويُرسل لبريد ولي الأمر.

5. **الحماية والدفاع الذاتي (Self-Defense & Anti-Tampering)**:
   - حارس مراقبة مزدوج (Mutual Watchdog) لحماية الخدمة من الإغلاق عبر Task Manager.
   - إجبار سياسات السجل (تعطيل التصفح الخفي، حظر إضافات الـ VPN، قفل البروكسي).
   - قفل المتصفحات المحمولة غير المعتمدة (Process Lockdown).

6. **إلغاء التثبيت المحمي بكلمة مرور (Uninstall with Password)**:
   - أداة حذف آمنة وسريعة بنقرة واحدة (`scripts/uninstall.bat`) تطلب كلمة المرور المشفرة بـ `bcrypt`، وتستعيد كافة إعدادات الجهاز الأصلية وتزيل أي سياسات وتوقف العمليات فوراً.

## 🚀 طريقة التشغيل

### التشغيل الفوري الشامل:
انقر مرتين على:
```
scripts\run_all.bat
```
أو عبر الطرفية:
```bash
venv\Scripts\python.exe run.py
```

### إلغاء التثبيت والاستعادة:
انقر على:
```
scripts\uninstall.bat
```
وأدخل كلمة مرور ولي الأمر (الافتراضية: `haseen2026`).

## 📂 هيكل المشروع
```text
Haseen_Kids/
├── core/                  # نواة الخدمة، التتبع، الحماية، التحديث، الموافقات
├── proxy/                 # البروكسي المحلي وهرم الفلترة ثلاثي المراحل
├── youtube/               # محرك استخراج البث بدون إعلانات و SponsorBlock
├── database/              # إدارة قاعدة بيانات SQLite والجداول والقوائم
├── ui/                    # واجهة الطفل ولوحة تحكم ولي الأمر (PyQt6)
├── scripts/               # سكربتات التشغيل والتثبيت والإلغاء
├── tests/                 # اختبارات الوحدة، اختبارات الثغرات، واختبارات الأداء
├── uninstall.py           # أداة إلغاء التثبيت المحمية بكلمة مرور
└── run.py                 # المشغل الرئيسي الموحد
```
